## 有效实现约定

- 单个 Next.js App Router 实例，`app/api/[[...route]]/route.ts` 仅适配 Hono；设备业务在 `server/`，共享 Zod 契约在 `shared/`。保留 React、TypeScript、pnpm 与现有 shadcn/Base UI 组件体系。
- 前端业务 API 统一由 TanStack Query v5 和导出的 hooks 管理：`useChannels`、`useDevice`、`useRecordings` 及媒体会话创建/关闭、状态与音频 hooks。浏览器共享 QueryClient，服务端渲染隔离；请求保留 Zod 校验、取消、超时与清理。通道共享 30 秒新鲜缓存，录像按通道/日期区分，手动刷新关闭旧播放器；不自动重试，不因窗口聚焦或恢复网络刷新查询，本机 API 不受浏览器离线标记暂停。HLS 播放列表/分片由播放器加载。**已验证（自动测试）**；实机与 Safari 的既有验收范围见下文。
- 实时源为 RTSP，历史回放源为 ISAPI HTTP 文件下载；FFmpeg 只做音视频 stream copy，浏览器本机解码。支持 H.264 / H.265，G.711 A-law / μ-law 由 Web Audio 解码；其他音频编码待支持。MediaMTX 尚未接入。
- 首页支持 1 / 2 / 4 / 8 / 16 路、默认 4 路，进入页面和增加窗口均不自动取流；`/playback` 为单窗口文件回放，复用窗口和播放器组件。
- 界面以画面为主体：实时页使用紧凑工具栏、可折叠通道列表和窗口浮动控件；回放页将摄像头/日期/刷新集中在顶部，选片后优先显示播放器，片段列表按需展开。设备详情按需读取，搜索编码和维护说明不常驻显示；当日覆盖摘要排除尚未到来的时段。**已验证（自动测试、Chrome 合成数据页面）**，不扩大真实媒体与 Safari 的验收结论。
- 实时通道列表支持可中断的 280ms 收展过渡：桌面调整列宽、手机调整高度，画面区域同步布局；关闭内容立即退出键盘/辅助技术导航，保留列表滚动和播放器实例。减少动态效果时直接切换。**已验证（自动测试、Chrome 合成数据页面）**。
- 回放页的“设备信息”入口位于刷新旁，弹层以型号为主，固件、摄像头数量及时区为次级参数；北京时间不再独占工具栏位置。页面、通道侧栏、手机通道列表、视频墙、时间轴、下拉列表、超高弹层与直播长错误统一使用 shadcn Scroll Area，动态内容通过 Content 尺寸观察更新滚动条。**已验证（自动测试、Chrome 合成数据页面）**。
- 录像日期、今日日期和时间显示默认 **UTC+8 / `Asia/Shanghai`**，通过服务端 `NVR_TIME_ZONE` 配置；内部/API 使用 UTC、左闭右开区间，不依赖浏览器或容器本地时区。
- 当前固件默认 `NVR_RECORDING_TIME_MODE=device-local`，仅在搜索接口边界适配带 Z 的设备本地时间；显式偏移保持原义，标准 UTC 固件可设为 `utc`。日末包含式边界在 API 中还原为次日零时，界面显示 `24:00:00`；时间核对提示已移除，兼容字段 `warnings` 为空数组。原始媒体 URI 不改写。
- **搜索时间可能被查询边界裁剪，不能用 `segment.startAt + video.currentTime` 推算真实录像时刻。** 全天时间轴目前用于选片段；播放器定位表示文件内部位置。进度条按完整设备标签跨度的预估时长保持刻度并区分已读取范围，读取完成后校准实际总长；日界片段通过有取消和短时限的邻日查询恢复完整跨度，失败则显示时长确认中。支持输入相对时分秒、未读取目标等待/取消及最终越界提示。
- 网页联调默认 `pnpm dev` 与热更新；文件监听受限时可使用 `WATCHPACK_POLLING=true pnpm dev --webpack --port <port>`。构建留到交付验收或生产特有问题排查。`dev` / `start` 使用 Next.js 默认监听地址；启动参数变更后的局域网访问尚待实测。
- 只读访问设备；凭据、原始 `playbackURI`、序列号/MAC 和真实画面/声音不进入公开响应、日志或测试产物。媒体来源仅取服务端配置和可信查询结果，禁止客户端提交任意 URL。会话保留超时、TTL、并发/容量上限及取消/关闭/失败清理。

需要保留的设备兼容细节：`searchResultPostion` 使用原厂拼写；`Enable=false` 不代表没有录像；通道名称通过 `SrcDescriptor/SrcChannel` 显式关联；搜索编码可能与媒体不符，实际编码以容器为准。
